# Titanic Survival Prediction

A beginner machine-learning project that predicts Titanic passenger survival.

## Methods
- Data preprocessing
- Logistic regression
- Support vector machine (RBF kernel)
- Accuracy and confusion-matrix evaluation
- Chi-square test of association

## Results
- Logistic regression accuracy: 80.4%
- SVM accuracy: 81.6%

## Dataset
Download `train.csv` from the
[Kaggle Titanic competition](https://www.kaggle.com/competitions/titanic/data).
Place it beside the notebook before running the project.

## Run
Open `titanic_survival.ipynb` in Jupyter Notebook, JupyterLab, or Google Colab.
